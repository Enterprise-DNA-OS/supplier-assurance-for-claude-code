# Follow up supplier corrective actions

Read CLAUDE.md.

```bash
npm run assurance -- corrective-actions --json
```

Prioritise overdue and critical findings. Positive days_overdue means late. Negative means time remains.

If a name is ambiguous, show the candidates and stop the change. Report the current result and the next responsible owner. Nothing sends or publishes.
