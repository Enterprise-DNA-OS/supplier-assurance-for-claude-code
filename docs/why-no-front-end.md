# Why there is no front end

A weekly supplier meeting needs a register, evidence dates, decisions, scorecards and assigned actions. Those are useful as records with repeatable commands. The agent reads the current database, prepares an answer and records an authorised change.

A supplier portal gives outside suppliers a login, uploads and guided forms. A mobile app gives field staff a camera. A workflow board shows stages visually. This free base provides none of those interactions. It has no built-in authentication, external risk feeds, signature service or attachment storage.

`npm run view` renders static review snapshots and `npm run docs` renders printable paperwork. They are read-only outputs, not an application that changes records. They refresh only when rendered again. Local PGlite runs without a server, but this does not make agent access or third-party evidence available offline.
